# 三请求教学示例

这两个输入只用于把调度决策讲具体。资源和单价沿用固定公开SDK，三个请求由本地构造；为便于阅读只用单卡，不是八卡正式评分输入，也不计入481条冻结验证矩阵。当前源码保持冻结，未根据示例调参。

| 示例 | 输入 | 实际输出 | 结论 |
| --- | --- | --- | --- |
| 相邻对齐小读 | [输入](相邻对齐小读输入.json) | [输出](相邻对齐小读输出.json) | 合并DIRECT，J=6；分别DIRECT为10 |
| 相邻非对齐读取 | [输入](相邻非对齐读取输入.json) | [输出](相邻非对齐读取输出.json) | 分别AGGREGATE，J=48；全部合并AGGREGATE为98 |

[候选方案对照](候选方案对照.json)保存输入哈希、策略源码哈希、固定SDK提交，以及六个候选的完整计划、完成事件和指标。所有候选均由官方模拟器执行，再经nds_validate独立校验；候选比较说明不是只靠手算时间。

在材料根目录运行：

```bash
python3 run.py solve --prebuilt --input 02_算法方案/示例/相邻对齐小读输入.json --result aligned.json
python3 run.py solve --prebuilt --input 02_算法方案/示例/相邻非对齐读取输入.json --result unaligned.json
```

预计分别得到J=6、J=48。输入到输出的逐步解释及缓存预算算例见[算法设计](../算法设计.md)。
