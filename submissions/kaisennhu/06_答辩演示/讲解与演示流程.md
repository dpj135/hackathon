# 答辩与现场演示

建议讲解10分钟，演示3分钟。按“问题→流程→具体决策→证据与边界”展开，避免先罗列算法模块。

| 时间 | 内容 | 材料 |
| --- | --- | --- |
| 1分钟 | 输入指定数据与目标，调度器优化完整Trace的时间＋调用成本 | [入门说明](../00_快速入门/方案介绍.md) |
| 2分钟 | 到达时分块、估价、采样组数与选路；完成后判断是否缓存 | [算法设计](../02_算法方案/算法设计.md) |
| 3分钟 | SSD从100B开始、5MiB分给两卡：容量与对齐、分块、FALLBACK与J=635 | [逐步示例](../02_算法方案/双卡读取逐步示例.md) |
| 2分钟 | 复用频率与证据新鲜度检查，再算净收益与预算；满池仍允许新热点替换 | 算法设计第3节与缓存算例 |
| 2分钟 | 成绩、验证范围与适用边界 | [验证报告](../05_验证结果/验证报告.md) |

现场运行：

```bash
python3 run.py quick
python3 run.py solve --input 02_算法方案/示例/双卡分配输入.json --result result.json
python3 run.py demo
```

demo比较七类场景：连续小读、热点复用、小池大工作集、小对象、短TTL、热点迁移、稀疏非对齐读取；双方结果都经过官方回放。观察J及时间、调用费、提升和命中，不能只比较命中率。

答辩边界与验证口径统一以算法设计和验证报告为准。
