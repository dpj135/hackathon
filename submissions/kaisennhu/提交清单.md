# 正式提交清单

本材料以主线提交`519ef500ad5f685a7e7e010c076960610018c20b`的调度策略为基准。唯一策略源码为`solution.cpp`，程序、报告与演示使用同一实现。

| 参赛要求 | 提交内容 |
| --- | --- |
| 1. 调度算法源代码 | [solution.cpp](01_调度算法源代码/player/solution.cpp)，C++17 |
| 2. 可执行程序或容器镜像 | [Linux x86_64程序目录](02_可执行程序/linux-x86_64/)，含player、官方validator及构建哈希 |
| 3. 输入输出格式说明 | [程序入口与JSON协议](03_输入输出说明/输入输出格式.md)，附可运行示例 |
| 4. 算法设计和复杂度文档 | [算法设计](04_算法设计与复杂度/算法设计.md)，正文讲流程，附录A讲复杂度与搜索预算 |
| 5. 自动化测试及复现脚本 | [run.py](run.py)、[复现手册](05_自动化测试与复现/测试操作手册.md)和[交付核验](05_自动化测试与复现/verify_submission.py) |
| 6. 性能和资源开销报告 | [验证报告](06_性能与资源报告/验证报告.md)、[资源开销](06_性能与资源报告/资源开销.csv)及逐输入记录 |
| 7. 评委展示PPT | [答辩介绍.pptx](07_答辩PPT/答辩介绍.pptx)，涵盖观察、设计、数据结构、baseline对照、收益与边界 |

目录、README和本清单采用相同的1—7顺序，PPT位于最后。检查交付完整性可运行`python3 05_自动化测试与复现/verify_submission.py`；逐文件摘要见[SHA256清单](文件校验SHA256.txt)。

完整克隆仓库后可离线构建与运行基础测试。固定SDK位于仓库`public/`，构建时校验后复制到源码目录；大体积合成输入由脚本按冻结种子重建。外部补充集有独立的固定提交与获取命令，不混作官方隐藏数据。
