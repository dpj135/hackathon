## 运行

完整克隆仓库，在本目录执行。需要Linux/WSL、C++17编译器、make、nm（binutils）和Python 3.10+，不需要GPU。

```bash
python3 run.py solve --input 02_算法方案/示例/双卡分配输入.json --result result.json
python3 run.py quick
python3 run.py score
python3 run.py demo
```

入口从仓库`public/`复制并校验固定版本SDK到本地构建目录，保持官方文件不变；可重建测试数据按需生成并核验哈希。构建产物、扩展输入、原始运行日志和文档导出文件不纳入Git。详细来源见[材料来源](01_题目与依据/材料来源.md)。

## 验证结论

策略内部不运行模拟器；公式估价与DP完成决策，官方engine只在外层执行与评分。

公开39条全部合法：方案 **88.4555/90**，官方贪心 **67.1981/90**。655条输入各三次运行和回放通过，173项专项检查通过。

292条扩展对照中195条优于贪心、1条持平、96条更差。2MiB块上限仍是启发式参数，不是赛题限制。完整成绩、回退和估价边界见[验证报告](05_验证结果/验证报告.md)。
