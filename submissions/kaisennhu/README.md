## 运行

完整克隆仓库，在本目录执行。需要Linux/WSL、C++17编译器、make和Python 3.10+，不需要GPU。

```bash
python3 run.py solve --input 02_算法方案/示例/双卡分配输入.json --result result.json
python3 run.py quick
python3 run.py score
python3 run.py demo
```

入口从仓库`public/`复制并校验固定版本SDK到本地构建目录，保持官方文件不变；可重建测试数据按需生成并核验哈希。构建产物、扩展输入、原始运行日志和文档导出文件不纳入Git。详细来源见[材料来源](01_题目与依据/材料来源.md)。
