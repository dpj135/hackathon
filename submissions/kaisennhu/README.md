完整克隆仓库后，在本目录执行；环境为Linux/WSL、C++17编译器、make、nm（binutils）及Python 3.10+。

```bash
python3 run.py solve --input 02_算法方案/示例/双卡分配输入.json --result result.json
python3 run.py quick
python3 run.py score
python3 run.py demo
```

构建入口从仓库public校验并复制SDK，按需重建测试输入。依赖与来源见[材料来源](01_题目与依据/材料来源.md)；结果写入本地运行目录。
