# NDS 多路径IO分配聚合与缓存提升调度

本包提供一套可运行的C++17在线方案：观察窗口调度与复用感知缓存。源码、Linux可执行程序、说明文档、测试证据和答辩材料对应同一冻结实现。

**第一次阅读：[方案介绍（网页）](00_快速入门/方案介绍.html) · [方案介绍（Word）](00_快速入门/方案介绍.docx)。** 不需要预先了解存储或NPU。

公开原始39条自动分 **89.9792/90**，官方贪心 **67.1981/90**；另10分由评委人工评分。438条输入各三次，共1314次提交策略运行与官方独立回放通过。116项功能/边界/评分门禁检查通过，74项另做ASan/UBSan检查。

## 运行

Windows可以直接解压和阅读文档。运行程序使用Linux或WSL。预编译程序适用于Linux x86_64；源码构建需要C++17编译器、make、Python 3.10或更高版本。算法和测试不依赖GPU或网络。

```bash
python3 run.py solve --prebuilt --input 03_程序/data/small_mixed.json --result result.json
python3 run.py quick
python3 run.py score
python3 run.py demo
```

第一条校验预编译程序及源码哈希、运行输入并自动回放。其余命令从源码构建。完整验证用extended，177条贪心对照用compare，规模测试用scale；详见04目录操作手册。输出默认保存在新的运行结果目录。
