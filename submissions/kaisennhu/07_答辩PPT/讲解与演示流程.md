主讲材料为[答辩介绍.pptx](答辩介绍.pptx)，共12页，含封面。风花雪月战队，队员刁鹏杰、胡海川、杜杰贵；选题为“24.NDS多路径IO分配、聚合与缓存提升算法”。

## PPT内的代码可视化演示

第5页使用原生PPT动画，四次点击同步展开左侧代码与右侧数据，不需要网络或运行环境。代码按半开区间`[i,j)`简写，与主线`solution.cpp`中的快速DP对应；演示展示预先核验的执行过程，放映时不执行C++。

1. **输入与初始化：** 三个同卡请求覆盖SSD的`[0,512)`、`[512,1024)`、`[1024,1536)`；各自目标均对齐。初始化`dp[0]=0`，其余不可达。
2. **联合枚举：** 对每个起点、终点及路径检查合法性。整组三条路径的实际估价分别为DIRECT 5.406、AGGREGATE 32.820、FALLBACK 22.559。
3. **更新状态：** `dp[1]=3.135`、`dp[2]=4.271`。整组成本5.406低于从另外两个前缀接续的7.406，故保留`prev[3]=0`与DIRECT；展示值四舍五入到小数点后三位。
4. **回溯与输出：** 回溯`3→0`，生成一个operation、一条1536B DIRECT和三份请求映射。官方回放得到`T=4μs、CPU=2、NPU=0、J=6`；分别读取时J=10。本例没有跨时刻复用，不PROMOTE。

E是用于候选排序的工作量估价，不是最终J。估价与主线代码一致，实际计划和J经官方回放验证。计数搜索在此例也选择一个DIRECT组。输入和输出随材料提供，见[相邻对齐小读输入](../04_算法设计与复杂度/示例/相邻对齐小读输入.json)和[输出](../04_算法设计与复杂度/示例/相邻对齐小读输出.json)。

第7页五次点击依次展开四道缓存准入判断和数值例子。例中提升投入100、需替换池容量的1/8，准入门槛112.5；第二次完成预算104，跳过；第三次完成预算156，提升。它是公式教学假设，非实测Trace。

用PowerPoint放映模式单击或方向键推进。文字、图形和代码均可编辑，普通编辑视图及静态导出显示完整内容。使用微软雅黑；非Windows环境可能替换为系统字体。

## 命令行复现

在材料根目录执行七场景演示：

```bash
python3 run.py demo
```

该入口准备依赖和输入，调用`demo.py`对比官方贪心与本方案的J、路径、提升、命中和驱逐，并做官方回放；结果保存在`运行结果/`。

只复现PPT的两个最小前台例子：

```bash
python3 run.py solve --prebuilt --input 04_算法设计与复杂度/示例/相邻对齐小读输入.json --result aligned.json
python3 run.py solve --prebuilt --input 04_算法设计与复杂度/示例/相邻非对齐读取输入.json --result unaligned.json
```

分别得到合并DIRECT的J=6与分别AGGREGATE的J=48；观察调用费和Trace时间，不能只看合并程度或命中率。完整的估价、复杂度和缓存公式见[算法设计](../04_算法设计与复杂度/算法设计.md)；成绩、统计口径与资源开销见[验证报告](../06_性能与资源报告/验证报告.md)。
