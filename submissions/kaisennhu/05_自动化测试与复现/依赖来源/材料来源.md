# 材料来源

| 材料 | 来源与用途 |
| --- | --- |
| 赛题 | 参赛人提供的原始Word；[原件哈希](原始赛题哈希.txt)用于核对 |
| 官方SDK与39条公开输入 | [仓库public](https://github.com/dpj135/hackathon/tree/dd321261c9d3002d548a8097fd29affc019034b8/public)，固定提交`dd321261c9d3002d548a8097fd29affc019034b8`；[组件与输入哈希](SDK来源与哈希.json) |
| 扩展输入 | 本地生成器和外部补充数据；来源、数量及重建命令见[复现手册](../测试操作手册.md) |
| 提交策略 | `01_调度算法源代码/player/solution.cpp` |

构建时从public复制SDK，保持engine、validator、评分器和参考成本原样。评分由官方脚本计算，自动项共90分，文档10分由评委评价。所有合成负载作为可见回归数据；仿真J与真实硬件性能实测不同。

策略堆内存按官方`policy_peak_mb`计量；框架、进程RSS与策略内存分开统计。官方贪心对照通过`greedy_policy.cpp`构造原GreedyBaseline，并链接同一官方计量入口；`engine_checks.py`核验与原入口输出一致。
